# User-home storage and traceable records — 2026-09-30

New installations default to `~/.durebak`. Explicit `--data-dir`, `DUREBAK_DATA_DIR`, and `XDG_DATA_HOME` retain precedence. With no overrides, an existing legacy database is selected without moving it; databases at both default locations require an explicit choice. No schema migration is introduced.

`paths` reports local storage locations without creating files. A supplied session selects its own recorded data directory. `register` without `--out` creates a private random credential filename under `credentials/`. `export` without `--out` creates a workspace-scoped, content-addressed Markdown snapshot under `records/`; the original database remains authoritative. Event metadata, messages, task state and artifacts continue to persist automatically. Markdown exports remain explicit and do not capture full native host conversations or automatically train models.
