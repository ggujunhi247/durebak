# Architecture Decision Records

ADR은 선택한 구조와 이유, 대안, 비용을 보존한다. Accepted는 설계 선택을 뜻하며 구현 완료나 호환성 검증 완료를 뜻하지 않는다. 변경 시 기존 결정을 지우지 않고 새 ADR로 대체 관계를 기록한다.

| ADR | 결정 | 상태 |
| --- | --- | --- |
| [0001](0001-harness-backend-model-separation.md) | Harness / backend / model 분리 | Accepted — 구현 예정 |
| [0002](0002-runtime-owns-coordination.md) | 협업 상태와 실행 소유권은 두레박 runtime에 유지 | Accepted — 부분 구현 |
| [0003](0003-public-source-private-runtime.md) | 공개 소스와 비공개 런타임 데이터 분리 | Accepted — 공개 업로드 전 검증 필요 |
