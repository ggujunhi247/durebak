# 기록 문서 템플릿

아래 파일은 향후 결정적 renderer가 출력할 형식을 설명하는 문서 템플릿이다. 중괄호 값은 실제 실행에서 채워질 필드이며 실행·검증을 수행했다는 뜻이 아니다. runtime 상태의 원본은 DB와 artifact 저장소다.

- [작업 결과](run.template.md): 어느 revision과 기준을 검증했고 무엇이 남았는지.
- [결정과 배움](knowledge.template.md): 선택 이유, 근거, 적용 범위, 채택 상태.

기본 저장은 로컬 데이터 root다. 프로젝트에 export한 문서를 Git에 올릴지는 사용자가 결정한다. 원본 로그 전체와 비공개 대화는 이 템플릿에 자동 첨부하지 않는다.
